# 🧬 Oráculo de Bolsillo — Modelo Vectorial

Enseña el **modelo de acceso vectorial**: cuándo usar índices de similitud (pgvector, Qdrant, Weaviate, Pinecone) para búsqueda semántica sobre embeddings.

**Proyecto:** RAG (Retrieval-Augmented Generation) con citas verificables

**Rivales:** pgvector vs Qdrant vs Weaviate vs Pinecone

**Veredicto:** Usa vectorial cuando necesitas búsqueda por similitud semántica. Evítalo para búsqueda de palabras clave (la búsqueda exacta existe y es más barata).
