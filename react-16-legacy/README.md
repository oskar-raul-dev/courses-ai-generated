# ⚛️ React 16 Legacy

Curso práctico de React 16 para ingenieros que vienen de otros paradigmas. Cubre fundamentos hasta patrones avanzados, sin asumir experiencia previa en JavaScript moderno o ecosistema React.

## 🎯 Objetivo

Dominar React 16: componentes, ciclo de vida, estado, props, hooks (introducción a FC), manejo de efectos. Proyecto integrador: aplicación real que responde a cambios sin recargar.

## 📚 Estructura

- **Lecciones:** 0 (setup) → 1, 2, 3... progresión gradual
- **Apéndices:** Profundidad, patrones avanzados, gotchas comunes
- **Ejercicios:** 🟢 básicos → 🟠 complejos
- **Criterios de salida:** Concretos y verificables

## 🛠️ Stack

React 16, Create React App, ES6+, HTML5, CSS3. Todo corre local, sin servidores externos.

## 🚀 Empezar

Lee las lecciones en orden. Cada una construye sobre la anterior. No saltes capítulos.
