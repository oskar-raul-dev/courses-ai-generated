# Cursos de IA

Colección de cursos educativos sobre paradigmas modernos de software engineering. Cada curso enseña mecanismos antes que abstracciones, con énfasis en medición y decisiones justificadas.

---

## 📚 Cursos

### 🔍 tutorial-rag
**Retrieval-Augmented Generation** — Dos versiones del mismo curso: una larga (65 guías, 38–43 semanas, Java + Spring AI + pgvector) para producción, y una corta (10 semanas, Python + ChromaDB) para aprender rápido. Ambas construyen un asistente documental funcional que responde preguntas, cita fuentes y se abstiene cuando falta evidencia. Filosofía: mecanismo antes que abstracción. Criterio: saber medir, no solo implementar.

### 🗄️ ruta-no-sql
**Ruta NoSQL** — Colección de cursos sobre familias NoSQL (documentales, grafos, series temporales, etc.). Cada curso enseña modelo de acceso, no productos. Incluye benchmarks contra competidores reales en `scripts/vs.ts`. Criterio: entender cuándo NO usar lo que acabas de aprender.

### 🎨 vue2-legacy-for-backend-devs
**Vue 2 para ingenieros de backend** — Curso de Vue 2 orientado a quiénes vienen del backend. Estructura: tronco (12 lecciones fundamentales F0–F11), después rutas opcionales (Quasar, Vuetify, Nuxt). Incluye complemento de integración con MongoDB. Objetivo: backend engineers productivos en frontend sin romantizar JavaScript.

### 🧠 maestria-ia
**Maestría en IA** — (En construcción) Especialización profunda en aplicaciones de IA. Cobertura breadth en arquitecturas, modelos, y patrones modernos.
