# 📴 Bitácora de Campo — Modelo Offline-First

Enseña el **modelo de acceso offline-first**: cuándo usar sincronización eventual (CouchDB, PouchDB, Firebase/Firestore, ElectricSQL) para aplicaciones que funcionan sin conexión.

**Proyecto:** Inspecciones de campo con sincronización eventual

**Rivales:** CouchDB+PouchDB vs Firebase/Firestore vs ElectricSQL

**Veredicto:** Usa offline-first cuando tus usuarios trabajan sin conexión intermitente. Evítalo si necesitas consistencia fuerte en tiempo real.
